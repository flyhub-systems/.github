# FlyHub

FlyHub is a modular platform for aviation operations, designed to connect aircraft, people, flight data, telemetry, and external systems.

## Engineering principles

* Build incrementally.
* Prefer simple solutions before abstractions.
* Avoid premature distributed architecture.
* Treat security and observability as engineering fundamentals.
* Keep architectural decisions explicit and documented.
* Use AI to implement decisions, not to silently make architectural ones.

## Current stage

The project is currently establishing its engineering foundation before beginning the first functional milestone: **Identity & Authentication**.
